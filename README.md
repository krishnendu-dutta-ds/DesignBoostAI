# DesignBoost AI

A browser-based workspace for creating and managing design systems, including color palettes, typography, spacing, components, and design tokens.

Live site: https://krishnendu-dutta-ds.github.io/DesignBoostAI/

Workspace data is saved locally in the browser. Projects can be imported from or exported to JSON.

## Getting started

Requires Node.js.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
